## 节点列表

具体用法请查看节点的鼠标悬停提示。

### ⚡ 基础流程

**【模型加载】** 在一个节点里加载扩散模型、CLIP 和 VAE，供提示词编码、采样和解码使用。图像工作流可以只加载一个 VAE，需要分别处理画面和声音的视频工作流可以加载两个。

**【Lora加载】** 按顺序把多个 LoRA 应用到模型，接入 CLIP 时也会将 LoRA 应用到 CLIP。可以独立控制每组 LoRA 的开关和强度，方便组合风格或比较效果。

**【CLIP编码器】** 把正向和负向提示词转换为采样器可用的条件，一次输出正面条件、负面条件和零化的负面条件。需要使用零化负面条件的工作流可以直接接对应输出。

**【解码采样器】** 接收模型、提示词条件和潜变量，把采样与 VAE 解码合在一个节点里。生成的图像可直接预览或继续处理，采样后的潜变量也能接到下一步。

### ⚡ 图像编辑

**【图像尺寸】** 在进入采样或编辑前统一处理图像、遮罩和潜变量的尺寸。可按目标比例裁剪或等比缩放，并输出处理后的宽高供下游节点使用。

**【编辑图像】** 把提示词、参考图和可选遮罩整理成采样所需的条件和参考信息，可用于修改原图、局部重绘或扩展画布。它还会传递补边信息，供后续的编辑对齐节点恢复成图尺寸。

**【编辑对齐】** 接在 VAE 解码之后，利用编辑图像节点传来的补边信息还原成图。普通编辑时可恢复参考图尺寸，扩图时则对齐到目标画布。

**【图像调色】** 用于出图后的细调，可以改善画面的明暗、色彩和清晰度。适合修正偏色、调整整体观感，或增强边缘和纹理。

**【色散效果】** 为图像轮廓添加彩边。可选择全图等量偏移或向外围逐渐增强的径向偏移，并调整方向、强度和配色。

**【图像滤镜】** 用内置或自行添加的 LUT 给图像套用一套调色风格。可调整滤镜强度，方便给单张图或一批图统一色调。

### ⚡ 文本编辑

**【离线翻译】** 用已安装的本地语言模型翻译提示词或其他文本，并将译文传给下游节点。依赖和语言模型准备好后即可离线使用，可翻译的方向由已安装的模型决定。

> 翻译模型下载地址，放至 `ST-tools\models\` 目录：
>
> - 英文 → 中文：https://data.argosopentech.com/argospm/v1/translate-en_zh-1_9.argosmodel
> - 中文 → 英文：https://data.argosopentech.com/argospm/v1/translate-zh_en-1_9.argosmodel
> - 其他语言模型索引参见：https://www.argosopentech.com/argospm/index/

### ⚡ DLSS 渲染

DLSS 渲染需要 NVIDIA RTX 显卡和配套程序。

**【渲染检测(DLSS)】** 运行一个小型渲染任务，检查本机能否正常使用 DLSS 神经渲染，并报告当前使用的光流后端。首次配置或渲染失败时可用它检查环境。

**【渲染图像(DLSS)】** 用 DLSS 放大图像并增强画面细节，适合出图后的超分处理。既能处理单张图，也能对一批图像逐张处理。

**【渲染视频(DLSS)】** 用 DLSS 放大并增强视频或连续图像帧，可用光流减少相邻帧之间的画面波动。处理后同时提供视频和图像序列，方便直接使用或继续逐帧处理。

> DLSS 程序下载地址：
> - 百度网盘：https://pan.baidu.com/s/1eawiyldNx2rNdBWmuSJq6g?pwd=9917
> - 夸克网盘：https://pan.quark.cn/s/84b582e1b2d1?pwd=UxM8
>
> 下载后将 `dlssnr.exe` 及配套运行库（包括 `nvngx*.dll`）放入 `ST-tools\dlssnr\bin\` 目录；也可通过环境变量 `DLSSNR_EXE` 指定程序完整路径。

DLSS 预设保存在 `config/dlssnr_presets.json`，重装或迁移前可备份。

## 系统补丁

凡是可在 ComfyUI 启动时应用的系统补丁，都可以通过 ST-tools 加载，补丁文件统一放在 [hotfix](./hotfix) 文件夹。

## 安装方法

1. 下载或克隆本仓库到 ComfyUI 的 `custom_nodes` 目录。
2. 重启 ComfyUI；更新后按 **Ctrl＋F5** 强制刷新页面，使原生节点的交互脚本同步更新。
3. 离线翻译缺少依赖时会尝试联网安装，可查阅 `requirements.txt`；需要离线运行时，请提前安装好依赖与语言模型。
4. 部分节点已重构，若旧节点未显示新增控件或输出，应从节点菜单重新添加同名节点。旧模型加载节点的 VAE 与设备选值可能因控件顺序调整而错位，请重新检查选择。
5. 管理器更新失败或怀疑本地文件过旧时，可重新安装本插件。
