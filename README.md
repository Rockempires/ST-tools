## 节点列表

## ⚡ 基础流程

**【模型加载】** — 一键同时加载 UNET、CLIP 和 VAE，CLIP 类型自动匹配 ComfyUI 当前环境。

**【Lora加载】** — 同时加载最多 4 个 Lora，每个可独立调节模型权重和 CLIP 权重。

**【CLIP编码器】** — 一次编码同时输出正面条件、负面条件和负面条件零化。

**【解码采样器】** — 集成采样器 + VAE 解码，一步完成采样和图像生成，支持返回 latent 供后续节点使用。每次执行后自动打印模型、LoRA、模式状态等关键信息。

## ⚡ 图像编辑

**【图像尺寸】** — 统一缩放图像、遮罩、latent，支持中心裁剪或等比缩放；支持画面方向（横/竖）切换；输出自动对齐 VAE 下采样倍率。

**【编辑图像】** — 图像编码 / 文本编码一体化节点，输出正负面条件、latent 与可选补边信息。三种模式：

- `flux2klein`（Flux 2 Klein）— 纯文本编码，参考图左上放置、右下补黑
- `qwenedit-krea2`（Qwen Image Krea2）— 视觉编码 + 官方编辑模板，参考图左上放置、右下补黑
- `qwenimage21`（Qwen Image 2.1）— 自动识别场景：同尺寸走纯编辑，输出自动放大回图像1原尺寸；不同尺寸走居中补黑扩图，输出即输入画布尺寸

qwenimage21 尺寸判定：宽/高**任一填 0** 或与图像1同尺寸 → 纯编辑；宽/高**都大于 0 且不同** → 扩图。

遮罩（可选）：白区重绘、黑区保留，自动羽化边缘。

**【编辑对齐】** — 串在 VAE 解码之后，按补边信息把 KSampler 输出还原回目标尺寸。纯编辑模式自动放大回图像1 原尺寸，扩图模式对齐到输入画布尺寸。

**【图像调色】** — 调整亮度、对比度、饱和度、Gamma、RGB 色彩平衡，附加模糊/锐化、HDR 效果、自适应画质增强。

**【图像滤镜】** — 加载 `.cube` 格式 LUT 滤镜，支持深度叠加和柔光混合两种调色模式，可调滤镜强度，内置动漫风格、烟熏装扮、电影复古等多种预设滤镜。

## ⚡ 文本编辑

**【离线翻译】** — 离线运行，支持中文、英语、苗语等语言互译，首次使用自动安装 argostranslate 依赖。

> 翻译模型下载地址，放至 `ST-tools\models\` 目录：
>
> - 英文 → 中文：https://data.argosopentech.com/argospm/v1/translate-en_zh-1_9.argosmodel
> - 中文 → 英文：https://data.argosopentech.com/argospm/v1/translate-zh_en-1_9.argosmodel
> - 其他语言模型索引参见：https://www.argosopentech.com/argospm/index/

## ⚡ DLSS 渲染

> 需 NVIDIA RTX 显卡
>
> 基于 NVIDIA DLSS 神经渲染（NGX），对图像或视频做超分辨率放大 + 神经渲染增强。三个节点均位于右键菜单 `石头工具 ▸ DLSS渲染` 子菜单下。
>
> DLSS 程序下载地址：
> - 百度网盘：https://pan.baidu.com/s/1eawiyldNx2rNdBWmuSJq6g?pwd=9917
> - 夸克网盘：https://pan.quark.cn/s/84b582e1b2d1?pwd=UxM8
>
> 下载后将 `dlssnr.exe`、`ffmpeg.exe`、`ffprobe.exe` 及 `nvngx*.dll` 放入 `ST-tools\dlssnr\bin\` 目录。

**【渲染检测(DLSS)】** — 跑一个微型测试任务，报告本机神经渲染是否可用、显卡设备、程序路径及光流后端。首次使用 DLSS 节点前建议先运行此节点确认环境。

**【渲染图像(DLSS)】** — 单帧或批次图像超分 + 神经渲染，每张图独立处理。支持 1–3 倍放大、4 套渲染预设（默认模型 + 预设配置一/二/三）、3 种渲染风格，可精细调节局部结构、色调、肤色、细节融合、色彩融合等参数。

**【渲染视频(DLSS)】** — 整段视频超分 + 神经渲染，带光流运动矢量保证帧间时序稳定不闪烁。支持接视频或图像帧序列输入，帧数据直传处理程序不走 ffmpeg、不产生临时文件，同时输出图像帧序列和封装好的视频（保留音频和帧率）。

## 安装方法

1. 下载或克隆本仓库到 ComfyUI 的 `custom_nodes` 目录。
2. 重启 ComfyUI。
3. 首次使用离线翻译节点时会自动安装依赖，可查阅 `requirements.txt`。
4. 部分节点已重构，若不能正常运行，应从节点菜单重新拉取同名节点替换。
5. 管理器更新失败或怀疑本地文件过旧时，请在管理器中卸载后重新安装本插件。
