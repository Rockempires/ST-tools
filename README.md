石头工具插件 — ComfyUI 多功能节点集合，涵盖图像处理、模型管理、文本处理、离线翻译、DLSS 超分神经渲染等。

## 节点列表

### ⚡ 基础流程

**模型加载**：同时加载 UNET、CLIP 和 VAE 模型，CLIP 类型自动同步 ComfyUI 原生 CLIPLoader 的更新。

**Lora加载**：同时加载最多 4 个 Lora，每个支持独立调节模型权重强度和 CLIP 权重强度。

**CLIP编码器**：一次编码同时输出正面条件、负面条件和负面条件零化。

**解码采样器**：集成采样器 + VAE 解码，一步完成采样和图像生成，支持返回潜空间供后续节点使用。

### ⚡ 图像编辑

**图像尺寸**：统一处理图像、遮罩、潜空间的尺寸，支持自定义尺寸或预设比例，中心裁剪或等比缩放，输出自动对齐 VAE 下采样倍率。接入 VAE 时直接输出编码后的潜空间，无图像输入时生成空潜空间。

**编辑图像**：接收 1–10 张参考图，输出文本条件、参考潜空间及补边信息。支持三种编辑模式：`flux2klein`（仅 VAE 编码参考）、`qwenedit`（视觉编码器 + 参考潜空间）、`boogu`（正负条件都写入参考潜空间，CFG 下抵消原图结构）。内部自动完成等比缩放、黑色画布补边对齐 VAE 单元。

**编辑对齐**：接收"编辑图像"节点输出的补边信息，对采样器生成的图像做反向裁剪，还原到等比缩放后的尺寸。

**图像调色**：调整亮度、对比度、饱和度、Gamma、RGB 色彩通道，附加模糊、锐化、HDR 效果、自适应画质增强。

**图像滤镜**：加载 `.cube` 格式 LUT 滤镜，支持深度叠加和柔光混合两种调色模式，可调滤镜强度，内置动漫风格、烟熏装扮、电影复古等多种预设滤镜。

### ⚡ 文本编辑

**离线翻译**：离线运行，支持中文、英语、苗语等语言互译，首次使用自动安装 argostranslate 依赖。

> 翻译模型下载地址，放至 `ST-tools\models\` 目录：
>
> - 英文 → 中文：https://data.argosopentech.com/argospm/v1/translate-en_zh-1_9.argosmodel
> - 中文 → 英文：https://data.argosopentech.com/argospm/v1/translate-zh_en-1_9.argosmodel
> - 其他语言模型索引参见：https://www.argosopentech.com/argospm/index/

### ⚡ DLSS渲染

> 需 NVIDIA RTX 显卡
>
> 基于 NVIDIA DLSS 神经渲染（NGX），对图像或视频做超分辨率放大 + 神经渲染增强。三个节点均位于右键菜单 `石头工具 ▸ DLSS渲染` 子菜单下。
>
> DLSS 程序下载地址：https://pan.baidu.com/s/1Rwx3tm9P6uywE9WavviRaw?pwd=9917
>
> 下载后将 `dlssnr.exe`、`ffmpeg.exe`、`ffprobe.exe` 及 `nvngx*.dll` 放入 `ST-tools\dlssnr\bin\` 目录。

**渲染检测(DLSS)**：跑一个微型测试任务，报告本机神经渲染是否可用、显卡设备、程序路径及光流后端。首次使用 DLSS 节点前建议先运行此节点确认环境。

**渲染图像(DLSS)**：单帧或批次图像超分 + 神经渲染，每张图独立处理。支持 1–3 倍放大、4 套渲染预设、3 种渲染风格，可精细调节局部结构、色调、肤色、细节融合、色彩融合等参数。

**渲染视频(DLSS)**：整段视频超分 + 神经渲染，带光流运动矢量保证帧间时序稳定不闪烁。支持接视频或图像帧序列输入，帧数据直传处理程序不走 ffmpeg、不产生临时文件，同时输出图像帧序列和封装好的视频（保留音频和帧率）。

## 安装方法

1. 下载或克隆本仓库到 ComfyUI 的 `custom_nodes` 目录。
2. 重启 ComfyUI。
3. 首次使用离线翻译节点时会自动安装依赖，可查阅 `requirements.txt`。
4. 部分节点已重构，若不能正常运行，应重新从菜单拉取替换工作流中同名节点。
