## 节点列表

## ⚡ 基础流程

**【模型加载】** — 同时加载 UNET、CLIP 和最多两个 VAE，便于视频工作流双VAE加载，CLIP 类型选项随 ComfyUI 当前环境提供。

- `VAE模型1`、`VAE模型2` 上下相邻，分别对应输出接口 `VAE1`、`VAE2`。
- 视频工作流可分别加载视频 VAE 和音频 VAE，再连接到对应的处理节点；节点不自动判断两者的用途。
- 图像工作流只需一个 VAE 时，填入任意槽位，另一个选择“无”，两个输出都会提供已加载的 VAE。
- 两个槽位选择同一文件时复用本次加载结果，避免重复读取权重。

**【Lora加载】** — 通过“LoRA 数量”动态增减加载单元，按顺序加载，不再固定为四组。

- 总开关控制整套加载模块；关闭时直接返回输入模型与 CLIP，不改动各路设置。
- 每路上方为 LoRA 选择栏，下方为强度输入与独立开关；不显示序号，强度无增减箭头，点击数值区域输入。
- 每路使用同一个强度同时作用于模型和 CLIP；不接 CLIP 时仅处理模型。
- 直接修改数量会即时展开或收起控件，节点高度随之调整；收起后再展开可恢复该路参数。
- 数量可转换为输入端口；外接上游时，在节点执行后同步显示数量，新增组默认选择“无”。
- 新建节点的默认宽度与模型加载节点一致；支持保存、恢复工作流和旧四组工作流迁移。

**【CLIP编码器】** — 一次编码同时输出正面条件、负面条件和负面条件零化。

**【解码采样器】** — 集成采样器 + VAE 解码，一步完成采样和图像生成，支持返回 latent 供后续节点使用。每次执行后自动打印模型、LoRA、模式状态等关键信息。

## ⚡ 图像编辑

**【图像尺寸】** — 统一缩放图像、遮罩、latent，支持中心裁剪或等比缩放；支持画面方向（横/竖）切换；输出自动对齐 VAE 下采样倍率。“自定义尺寸”开关使用“开启／关闭”中文状态。

**【编辑图像】** — 图像编码 / 文本编码一体化节点，输出正负面条件、latent 与补边信息；最终尺寸还原需在采样、VAE 解码后接入“编辑对齐”节点。三种模式：

- `flux2klein`（Flux 2 Klein）— 纯文本编码，参考图左上放置、右下补黑
- `qwenedit-krea2`（Qwen Image Krea2）— 视觉编码 + 官方编辑模板，参考图左上放置、右下补黑
- `qwenimage21`（Qwen Image 2.1）— 自动识别场景：同尺寸走纯编辑，由编辑对齐节点还原至图像1原尺寸；不同尺寸走居中补黑扩图，由编辑对齐节点还原至指定画布尺寸

qwenimage21 尺寸判定：宽/高**任一填 0** → 纯编辑；两者都大于 0 时，先将目标尺寸与图像1尺寸分别取整至 32 的倍数，再比较宽高：一致走纯编辑，不一致走扩图。

遮罩（可选）：白区重绘、黑区保留，按所选模式处理并对齐潜空间；节点没有统一的自动羽化步骤，需要柔化边缘时请提前处理遮罩。

**【编辑对齐】** — 串在 VAE 解码之后，按补边信息把 KSampler 输出还原回目标尺寸。纯编辑模式自动放大回图像1 原尺寸，扩图模式对齐到输入画布尺寸。

**【图像调色】** — 调整亮度、对比度、饱和度、Gamma、RGB 色彩平衡，附加模糊/锐化、HDR 效果、自适应画质增强。

**【图像滤镜】** — 加载 `.cube` 格式 LUT 滤镜，支持深度叠加和柔光混合两种调色模式，可调滤镜强度，内置动漫风格、烟熏装扮、电影复古等多种预设滤镜。

## ⚡ 文本编辑

**【离线翻译】** — 提供中文、英语、苗语选项，实际可用的翻译方向取决于已安装的语言模型。依赖与模型就绪后可离线翻译；缺少 argostranslate 时尝试联网安装依赖。插件会自动尝试安装 `models` 目录中的中英互译模型，其他方向需要先准备并安装对应模型。

> 翻译模型下载地址，放至 `ST-tools\models\` 目录：
>
> - 英文 → 中文：https://data.argosopentech.com/argospm/v1/translate-en_zh-1_9.argosmodel
> - 中文 → 英文：https://data.argosopentech.com/argospm/v1/translate-zh_en-1_9.argosmodel
> - 其他语言模型索引参见：https://www.argosopentech.com/argospm/index/

## ⚡ DLSS 渲染

> 需 NVIDIA RTX 显卡
>
> 基于 NVIDIA DLSS 神经渲染（NGX），对图像或视频做超分辨率放大 + 神经渲染增强。三个节点均位于右键菜单 `石头工具 ▸ DLSS渲染` 子菜单下。
>
> DLSS 程序下载地址：
> - 百度网盘：https://pan.baidu.com/s/1eawiyldNx2rNdBWmuSJq6g?pwd=9917
> - 夸克网盘：https://pan.quark.cn/s/84b582e1b2d1?pwd=UxM8
>
> 下载后将 `dlssnr.exe` 及配套运行库（包括 `nvngx*.dll`）放入 `ST-tools\dlssnr\bin\` 目录；也可通过环境变量 `DLSSNR_EXE` 指定程序完整路径。

**【渲染检测(DLSS)】** — 检测本机渲染环境，首次使用前建议运行一次。

**【渲染图像(DLSS)】** — 单张或批次图像超分与神经渲染，支持 1–3 倍放大，可调风格、强度、结构、色调、肤色及细节融合等参数。

**【渲染视频(DLSS)】** — 视频或图像帧序列超分与神经渲染，支持光流改善时序稳定性，同时输出帧序列和视频。视频输入保留音频与帧率；帧序列输入使用指定帧率，不补帧、不附带音频。

**预设使用：** 选择“预设配置一／二／三”后调节参数，修改会自动保存，无需运行渲染；切换时恢复对应参数，重启后仍可复用。图像与视频分别保存，同类节点共用档位；“默认预设（推荐）”恢复初始参数，不保存默认档内的修改。载入工作流时保留其自身参数，外接输入仍由上游控制。

配置文件为 `ST-tools/config/dlssnr_presets.json`，重装或迁移前可备份。HDR 模式为处理选项，节点输出仍为普通 RGB 图像。

## 安装方法

1. 下载或克隆本仓库到 ComfyUI 的 `custom_nodes` 目录。
2. 重启 ComfyUI；更新后按 **Ctrl＋F5** 强制刷新页面，使原生节点的交互脚本同步更新。
3. 离线翻译缺少依赖时会尝试联网安装，可查阅 `requirements.txt`；需要离线运行时，请提前安装好依赖与语言模型。
4. 部分节点已重构，若旧节点未显示新增控件或输出，应从节点菜单重新添加同名节点。旧模型加载节点的 VAE 与设备选值可能因控件顺序调整而错位，请重新检查选择。
5. 管理器更新失败或怀疑本地文件过旧时，可在管理器中卸载后重新安装本插件；重装前请备份 `config/dlssnr_presets.json` 及自行添加的模型等文件，重装后恢复。
